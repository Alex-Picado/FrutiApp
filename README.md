# FrutiApp Web

Aplicación de control de acceso desarrollada en Flutter Web.

## Requisitos

Flutter instalado con Dart compatible con ^3.13.0 y Google Chrome.

## Ejecución

Abre una terminal en la carpeta del proyecto y ejecuta:

flutter pub get
flutter run -d chrome
